# Users enumeration

Antes de empezar la enumeración web vamos a intentar conseguir nombres de usuarios del dominio, prueba varias técnicas
- `NetExec sobre SMB (--users)`: no devuelve resultados, el servidor no permite la enumeración anónima.
- `Impacket lookupsid.py`: tampoco funciona
- `kerbrute`: este si que funciona, `Kerbrute` aprovecha el protocolo `Kerberos 88` para validar nombres de usuario a través de un diccionario sin necesidad de contraseña. Esto se debe al funcionamiento del protocolo `Kerberos`, cuando un usuario quiere autenticarse su equipo envía al `DC` un mensaje llamado `AS-REQ (Authenticaction Service Request)`, que básicamente dice *Hola soy el usuario X quiero un ticket de acceso*. El `DC` puede responder de dos maneras distintas según el caso:
	- Si el usuario no existe responde con el error `KDC_ERR_C_PRINCIPAL_UNKNOWN` *no te conozco*
	- Si el usuario existe pero la contraseña es incorrecta responde con `KDC_ERR_PREAUTH_FAILED` *te conozco pero la contraseña no es correcta*
 
 Estos dos códigos de error son diferentes y es lo que aprovecha la herramienta `Kerbrute` para validar usuarios, envía miles de `AS-REQ` con nombres de usuarios de un diccionario y clasifica las respuestas.

`HHogan` pertenece al grupo `GPO Managers` que tiene el permisos `GenericWrite` sobre `Default Domain Policy`,  esta política está vinculada mediante `GPLink` al dominio `OFFICE.HTB` que a su vez contiene a todos los grupos y usuarios del dominio incluidos `ADMINISTRATORS y ENTERPRISE ADMINS`.
